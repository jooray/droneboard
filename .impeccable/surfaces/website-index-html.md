# Droneboard website — landing (all languages)

Mode: Persuade. Audience: everyday Gboard users who want privacy (EN/SK/CS/DE/ES), mostly arriving on phones from Zapstore, nostr or the projects showcase. Action: install via Zapstore (primary), APK from GitHub releases, Obtainium. Proof: live swipe demo, no INTERNET permission (with how to check it), swipe accuracy table, GPL-3.0. Czech/ES/DE and tablet resizing are labelled "coming", never available. Dictation screenshot with the headphone name is excluded. Nostr feed of 4 newest posts with empty/offline states. Static, no-JS fallback; reduced-motion fallback. Self-hosted fonts. Later: nostr picture/banner and possibly the app icon follow the new palette (icon: offer options, original stays a candidate — owner likes it).

## Direction contract

THESIS: An ECM-sleeve landing page: one fog-over-water photographic field, vast quiet space, and the keyboard as the only sharp object. It refuses the app-landing template (headline beside a phone mockup over a row of feature cards).

OWN-WORLD: Slate and fog greys from the photograph as the ground (#2E3A44 slate, #C9D1D3 fog, #F2F2EE off-white ink), one muted signal red (#B23A2E) only for the install line and focus. Small lowercase sans with generous tracking for display; quiet text sans for body; tabular numerals. Hairline rules, no cards, no shadows except the keyboard's own.

STORY: The visitor sees calm, reads "a keyboard that plays along. offline.", watches a swipe resolve into "ďakujem" with next words already waiting, believes it feels like Gboard and stays on the phone, and installs from Zapstore.

FIRST VIEWPORT: Full-bleed fog photograph; lowercase wordmark top-left, lowercase nav and language switch top-right; headline and one-line subcopy centred in the lower half; a small dark keyboard below them with the live swipe trace and prediction strip; "get it on zapstore" with the red underline plus "apk on github" and "obtainium" directly under the keyboard; a quiet scroll cue at the bottom edge.

FORM: Fog Sleeve (ECM covers), position 1 of the grounded list (IMPECCABLE'S PICK, chosen by the owner over the assigned direction). seed:667368a56e43a599. Raises kept from the declined hand: predictions visible before they are typed (algorave); the trace as one continuous emergence (darkroom); features as a strict track-listing grid, today vs coming (sneaker label grid); accuracy as a ruled table in tabular numerals (wax-pack stat backs).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
