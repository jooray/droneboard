- Swipe reads the sentence: the on-device neural model now helps pick the swiped word. When a swipe is unclear, the word that fits the sentence wins. On sloppy test swipes the first suggestion is right 10–15 % more often (Slovak 63 → 75 %, English 75 → 85 %), and precise swipes gain 3–5 %.
- Better suggestions while you tap: the model now ranks the word completions, so the strip shows the word you want sooner, also when you type without accents ("dak" offers "ďakujem"). In our tests you type about a third fewer letters than with 0.1.15.
- Emoji appear in the suggestion strip only when you have typed a whole word that names them, so they no longer take a slot while you type.
- The space bar no longer flashes grey on every tap.
- The trackpad (hold the space bar still) is easier to see: the keys fade almost completely while it is on.
- Swipe uses only the languages you turned on; English no longer joins when it is off.
- Fixed: if a swipe dictionary failed to load once, that language stayed off until the keyboard restarted, so swipe could offer only English words.
