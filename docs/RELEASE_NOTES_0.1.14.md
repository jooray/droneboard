- New languages: German, Spanish and Dutch, with swipe typing, on-device neural next-word prediction and emoji search. German uses QWERTZ like Gboard (QWERTY and the layout with ü ö ä keys are available too), Spanish has the ñ key. Long-press characters follow Gboard's order.
- Swiping over a key with an accent, such as ñ or ü, now finds the word.
- The keyboard is a bit smaller by default (85 %), closer to Gboard's size. Change it in Appearance → Keyboard height, or with the Size & position key.
- Dictation: if Offline Speech to Text isn't installed or isn't ready, the mic now explains what to do, with buttons to get it from Zapstore and to open the setup guide (including a tip for multilingual speakers).
