- Fixed: the keyboard could stop predicting in your languages (no Slovak suggestions, or no swipe) until it was restarted, typically in the morning after Android's nightly backup. When the keyboard started while the backup was running, Android sometimes gave it an incomplete list of the files in the app, and the keyboard then believed a language had no dictionary or model for as long as it kept running. It now checks each file directly and checks again if a file was not found.
- Self-healing: every time the keyboard is shown it checks that the dictionaries and models of your languages are loaded, and loads whatever is missing.
- "Save log" in About now includes the state of the prediction engines (which languages, what is loaded), and the log says where predictions come from. No typed text is in it.
